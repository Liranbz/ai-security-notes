# 03 — לזהות זה גם לטעות

גלאי מחזיר ציון. כדי להחליט אם להתריע, צריך לבחור סף. סף נמוך עשוי לתפוס יותר ניסיונות, אבל גם להטריד יותר משתמשים תמימים.

ב־[מחברת ההתחלתית](starter.ipynb) נשתמש בדוגמאות סינתטיות מתויגות, בגלאי פשוט ובגרף Precision/Recall לפי סף.

- **Precision**: מתוך ההתראות, כמה באמת סומנו כדוגמאות תקיפה?
- **Recall**: מתוך דוגמאות התקיפה, כמה זוהו?
- **False positive**: טקסט תקין שסומן בטעות.
- **False negative**: ניסיון שלא זוהה.

הגלאי הוא baseline מבוסס ביטויים, ולא מודל ML מאומן. הוא מדגים את תהליך ההערכה ומספק נקודת השוואה למודל עתידי. התוויות משקפות את ההקשר הסינתטי שהגדרנו; אותו ביטוי יכול להופיע גם בהקשר תקין.

## מה הלאה?

אספו נתונים מורשים ומגוונים, הגדירו הנחיות תיוג והפרידו train/validation/test לפי מקור או משפחת תרחישים לפני האימון. אפשר להשוות TF-IDF עם Logistic Regression ל־baseline, לבחור סף ב־validation ולהעריך פעם אחת ב־test שמור. אל תסיקו ביצועי ייצור מהמדגם הזעיר כאן.
